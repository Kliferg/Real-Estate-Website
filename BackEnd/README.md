# Northline Estates Backend

Small Node backend using JSON files as the starter database.

Run locally:

```bash
node server.js
```

API endpoints:

- `GET /api/company`
- `GET /api/models`
- `POST /api/inquiries`

Submitted inquiries are stored in `BackEnd/data/inquiries.json`. Owner email and phone details are stored in `BackEnd/data/company.json`.
