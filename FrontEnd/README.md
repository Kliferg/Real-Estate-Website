# Northline Estates Frontend

React frontend for the startup real estate website. Styling is handled with Tailwind utility classes in `app.js`, loaded through the Tailwind CDN in `index.html`.

Run locally:

```bash
node dev-server.js
```

Open `http://localhost:3000`.

The page uses placeholder image panels that can later be replaced with real photos or renders. The contact form can save inquiries to the backend and open email or SMS apps for direct owner contact.
